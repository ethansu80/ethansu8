# 苏海川博士毕业论文 LaTeX 源码

工作题目：**地震应急资源服务网络韧性演化与协同决策研究——以四川省泸定县为例**。

采用用户提供的四川大学博士论文模板。当前版本已建立八章三级目录，正文、摘要、新增理论推导及实验结果尚未完成。

```text
博士论文/
├── main.tex                 # 主文件与章节顺序
├── 论文信息.tex             # 题目、作者、学院及待确认信息
├── 参考文献.bib             # 经核验后录入的引用文献
├── 章节/                    # 摘要、八章正文、成果与致谢
├── 模板/                    # 川大模板、样式及配套图片
├── 工作底稿/                # 目录与证据映射
├── 编译说明.md
├── LICENSE.template         # 随原工程收到的许可文件
└── README.md
```

编辑论文从 [博士论文/main.tex](博士论文/main.tex) 开始；章节内容在 [章节目录](博士论文/章节/)，封面信息在 [论文信息.tex](博士论文/论文信息.tex)。

使用XeLaTeX编译，具体步骤见 [编译说明](博士论文/编译说明.md)。

```sh
cd 博士论文
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

本仓库同步论文源码、必要模板资源和编译说明。编译生成的PDF与临时文件、参考博士论文原件、小论文实验及投稿资料不随本次源码提交上传。

模板原有作者信息及许可文件均保留，模板目录中的许可与来源说明见 [论文工程说明](博士论文/README.md)。
