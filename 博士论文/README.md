# 博士论文工程

本目录是正式论文的唯一LaTeX主工程，使用四川大学博士论文模板。当前为八章三级目录初稿，正文、摘要与新增研究结果尚未完成。

| 文件或目录 | 作用 |
|---|---|
| `main.tex` | 编译入口、章节顺序与全局设置 |
| `论文信息.tex` | 论文题目、作者、学院及封面信息 |
| `参考文献.bib` | 后续经核验的实际引用文献 |
| `章节/` | 摘要、八章正文、研究成果与致谢 |
| `模板/` | 原川大模板的类文件、样式、图片与来源说明 |
| `工作底稿/目录与证据映射.csv` | 研究问题、现有材料与待补证据的对应关系 |
| `编译说明.md` | 本地编译步骤与文献处理说明 |

导师、学号、学位类别和日期等未确认信息暂留空。各节的 `\ThesisBlank` 是目录阶段的空白占位，撰写正文时移除。

## 八章结构

1. 绪论。
2. 文献综述与理论基础。
3. 地震应急资源服务网络建模与统一分析框架。
4. 地震扰动向应急资源服务退化的传导机制。
5. 道路可达性与资源供需耦合下的服务韧性演化。
6. 道路信息误差的决策影响与观测配置。
7. 道路抢通与资源调拨的联动决策机制。
8. 结论与展望。

第4章固定初始扰动，第5章给定外生恢复历程，第6章研究信息条件，第7章将抢通与调拨行动纳入联合决策。目录表示拟研究范围，不代表命题已证明或实验已完成。

## 模板来源与调整

沿用收到资料中的“四川大学-博士-论文LaTeX模板”，上游标识见 `模板/README.md`。收到的原始资料保持不变；本目录工程副本作了以下调整：

- 为原稿 `reference` 环境补齐缺失的空结束定义。
- 2026-11-13将章节、模板、模板资源与论文信息改为中文命名，并同步修改所有调用路径。
- 主文件用 `needspace` 避免目录章标题单独落在页末；长题目在论文信息文件中显式换行。

原模板的 `reference` 环境默认采用ACM样式，本工程未启用该环境，也没有使用模板示例文献。正文引用核验后，再启用主文件中预留的GB/T数字制样式。

随原工程收到的 `LICENSE.template` 与 `模板/LICENSE` 均原样保留；它们分别显示Apache-2.0和AGPL-3.0文本。本次整理保留各自的许可范围，没有为论文正文新增开源许可。

本模板的版本年份不代表已核对当前学校送审规范。
