# 编译说明

## 编译入口

使用支持UTF-8和中文的TeX环境，并选择 **XeLaTeX**。本机核验环境为Windows与MiKTeX；模板通过 `ctexbook` 使用中文字体，模板资源已随源码收入仓库。

在仓库根目录执行：

```sh
cd 博士论文
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

也可以在编辑器中打开 `博士论文/main.tex`，选择XeLaTeX后连续编译两遍，让目录页码更新。若仍提示交叉引用需要更新，再编译一遍。应从 `博士论文/` 目录编译，避免模板和章节的相对路径失效。

编译后生成 `main.pdf`。PDF和辅助文件被Git忽略，不需要提交。

## 文献与待填内容

当前 `参考文献.bib` 尚未录入正式条目，主文件中的文献命令暂未启用。后续核验文献后，启用：

```tex
\bibliographystyle{./模板/gbt7714-numerical}
\bibliography{参考文献}
```

同步移除主文件中暂用于目录展示的 `\chapter{参考文献}`，避免出现重复标题。首次录入文献后按XeLaTeX → BibTeX → XeLaTeX → XeLaTeX顺序编译，BibTeX的任务名为 `main`。

已安装Perl与latexmk的环境也可使用 `latexmk -xelatex main.tex` 自动处理编译依赖。本次核验使用XeLaTeX；本机缺少Perl，未使用latexmk完成构建。
